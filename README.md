# Evan Yibole — Personal Portfolio

A responsive React + Vite portfolio with a dark creative visual direction, purple/cyan accents, orbital hero graphic, project showcase, experience, skills, and contact links.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Before publishing

- Add a PDF resume and wire the navigation link if you want a resume download.
- Review all project descriptions and links.
- Add real project screenshots if you want richer project cards.
- Update the expected graduation date if it changes.

## Deploy

Pushes to `main` build this app and publish `dist/` to [evan0x.github.io](https://evan0x.github.io/). The resume stays available at `/resume.pdf`.
